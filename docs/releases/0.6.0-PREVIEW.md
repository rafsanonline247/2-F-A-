# 0.6.0-preview — release-candidate hardening (NOT a production release)

## Fixed in this release
- **jsQR provenance/license:** verified byte-identical to npm `jsqr@1.4.0` (Apache-2.0); `THIRD_PARTY_NOTICES.md` + `licenses/jsQR-APACHE-2.0.txt` added and bundled in the APK/Windows packages.
- **Android:** `FLAG_SECURE` (no screenshots, screen recording or recent-apps thumbnail). CI build asserts it and asserts no INTERNET permission.
- **Legacy v1 crypto removed** from `app/js/totp.js` (100k-iteration KDF, no AAD, unused).
- **Server headers:** `frame-ancestors 'none'` + `X-Frame-Options: DENY` (S6). `index.html` meta CSP verified identical to the server CSP (minus frame-ancestors, which meta cannot carry), so the APK/Windows shells are covered.
- **Tests:** 6 -> 13 (URI parse/round-trip, formatCode, forum.verifyCode success + bounds, password generator smoke, header/traversal/405, legacy-removal guard).
- **Version drift:** package.json, Android manifest (versionCode 6) and README all 0.6.0.
- **Reproducible CI builds:** `.github/workflows/release.yml` builds the APK (`packaging/android/build-apk-ci.sh`) and the Windows bundle. Without repository secrets the APK is signed with an EPHEMERAL preview key (a new signature each build — uninstall before updating). Set `ANDROID_KEYSTORE_B64` + `ANDROID_KEYSTORE_PASS` for a stable release key.

## Still open (blocks a production claim)
- Device evidence: no physical-device Android or Windows 10/11 test recorded.
- Vault stays in WebView localStorage (no Android Keystore / biometric / TPM) — ADR-001 native migration.
- Ownership/licence of the "supplied project" TOTP code not independently established.
- No Windows code-signing or MSI/MSIX; SmartScreen will warn. No Drive sync. No independent security review.
- `style-src 'unsafe-inline'` remains in the CSP (inline styles in the UI).
