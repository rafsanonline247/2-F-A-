# Release 0.4.0-preview — UI finalization + installable previews

- **Date:** 2026-10-20 (Asia/Dhaka) · **Branch:** `main` (direct commit per owner instruction)

## What is included

1. **UI finalized to the approved screenshots** (from `2FA.zip`): black theme, navy record cards with service mark, large spaced 6-digit codes, per-card countdown underline, search row with import/sort actions, FAB, bottom tab bar (2FA Codes / Passwords / Settings), Add-account screen (QR-image scan, provisioning URI, manual input), Settings with sections (Data storage / App safety / 2FA settings / System), Help-FAQ screen.
2. **Global Kalpurush font** (`app/fonts/kalpurush.ttf`, bundled unmodified; free font from okkhor52 — designer copyright retained, see the font note shipped with the font).
3. **Honest states only:** the fake "Synchronized" cloud UI from the old prototype is intentionally NOT reproduced; the Sync & Backup screen states that Drive sync is not implemented and offers the real encrypted backup/restore instead.
4. **Security logic unchanged:** SecureVault envelope (AES-256-GCM, PBKDF2-SHA256 600k, AAD), lock lifecycle, RFC 4226/6238 vector-tested engine. `npm test` 6/6 pass, `node --check` 7/7 OK (2026-10-20, Node v24.21.0).

## Known preview limitations (unchanged from docs)

No camera capture (QR by image file only), no biometric unlock, no Drive sync, no auto-update. The WebView preview is **not** the ADR-001 hardened end state (per-platform native remains the target). Production readiness is not claimed.
